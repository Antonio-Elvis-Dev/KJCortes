Como configurar
  1. No Google Cloud Console, crie um projeto e ative a YouTube Data API v3.
  2. Em Tela de consentimento OAuth, escolha "Externo" e adicione o seu e-mail como usuário de teste.
  3. Em Credenciais, crie um ID do cliente OAuth do tipo App para computador e baixe o JSON.
  4. Salve o arquivo como dados/youtube_client_secret.json e recarregue esta página.

Enquanto o projeto não passar pela auditoria do Google, os vídeos enviados pela API ficam privados. A cota padrão permite cerca de 6 envios por dia.

{% elif rede == "tiktok" %} {% if not conta %}{% if pub.configurado() %}Conectar TikTok{% endif %}{% endif %}
Como configurar
  1. Em developers.tiktok.com, crie um app e adicione os produtos Login Kit e Content Posting API (com Direct Post ligado).
  2. Peça os escopos user.info.basic e video.publish.
  3. Cadastre este endereço de retorno (redirect URI): {{ callbacks.tiktok }}
  4. Coloque a Client key e o Client secret no config.yaml, em redes: tiktok:, e reinicie o painel.

Até o app ser auditado pelo TikTok, só é possível postar como "Só eu" (privado). Peça a auditoria cedo, porque pode levar semanas.

Como conseguir o token
  1. A conta do Instagram precisa ser Profissional (Criador de conteúdo ou Empresa).
  2. Em developers.facebook.com, crie um app e adicione o produto Instagram ("API com login do Instagram").
  3. Em Configuração da API, adicione a sua conta e clique em Gerar token, com as permissões instagram_business_basic e instagram_business_content_publish.
  4. Cole o token aqui. Ele vale 60 dias e o painel renova sozinho enquanto estiver em uso.
